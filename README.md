# Развоз Квели — приложение для сортировки списков развоза ресторана "Квели"

Современное Android-приложение на **Kotlin + Jetpack Compose**, адаптированное из Telegram-бота.

## Возможности

1. **Современный Material 3 дизайн** (светлая/темная тема)
2. **Выпадающие списки по водителям** — нажми на карточку водителя, чтобы свернуть/развернуть
3. **Чекбоксы** — отмечай тех, кого уже развез (зачеркивается)
4. **Перемещение адресов** — кнопка ⇄ у каждого человека → выбрать водителя или район
5. **Выбор водителя** при входе:
   - №1 — СЗР + ЮЗР
   - №2 — ЦЕНТР + НОВЫЙ + НЧК (+ БОГДАНКА)
   - №3 — НЮР + КУГЕСИ (+ БОГДАНКА)
6. **Ввод списка** → красивая анимация обработки
7. **Итоговый список** с датой, слотами, группировкой по времени и районам
8. **Порядок водителей** зависит от выбранного:
   - Выбран №1 → сначала №1, потом №2, №3
   - Выбран №2 → сначала №2, потом №1, №3
   - Выбран №3 → сначала №3, потом №1, №2
9. **Кнопка «Завершить поездку»** → возврат на выбор водителя
10. **Справка** при первом запуске (тап в любое место — пропустить)

## Логика

Полностью перенесена из `processor.py` + `address_data.py`:
- Определение района (синонимы + fuzzy matching)
- Группировка по времени (слоты зависят от дня недели)
- Богданка → водителю с меньшим числом людей
- Роли (офф, кух, кар и т.д.)
- Поддержка «N чел.» и т.п.
