## 📌 О проекте

**Развоз Квели** — мобильное приложение для водителей, которые развозят сотрудников ресторана по домам после смены. Оно заменяет ручную сортировку списков в чатах: водитель вставляет неотсортированный текст, получает готовый маршрут по районам и времени и отмечает, кого уже отвез.

Приложение создано как адаптация логики Telegram-бота развоза под удобный Android-интерфейс: крупные кнопки, чекбоксы, быстрый перенос адресов и сохранение состояния поездки.

## 🌟 Зачем это нужно

| | |
|---|---|
| ⏱️ **Экономия времени** | Список сам раскладывается по районам и слотам — не нужно переписывать вручную |
| 🗺️ **Понятный маршрут** | Водители видят только свои районы и порядок объезда |
| ✅ **Контроль поездки** | Отметил человека — он зачеркнут, счетчики обновились |
| 📱 **Все в телефоне** | Работает без бота и чатов: открыл, вставил список, поехал |
| 💾 **Не теряется** | Закрыл приложение — при следующем запуске продолжаешь с того же места |

## 🎯 Основные возможности

### Для водителя

- 👤 **Выбор роли** — водитель №1, №2 или №3 со своими районами
- 📋 **Вставка списка** — неотсортированный текст из чата одним действием
- ✨ **Автосортировка** — районы, время, роли, «N чел.»
- 📂 **Карточки водителей** — свернуть / развернуть список
- ☑️ **Чекбоксы** — отметить, кого уже развез (счетчики уменьшаются)
- ⇄ **Перенос** — в другой слот, к другому водителю или в другой район
- ↕️ **Порядок в районе** — долгий тап → «Выше / Ниже» по маршруту
- 🏁 **Завершить поездку** — экран «Приятного отдыха» и полный сброс
- 💾 **Сохранение сессии** — после полного закрытия приложения состояние восстанавливается

### Районы и водители

| Водитель | Районы |
|----------|--------|
| **№1** | СЗР + ЮЗР |
| **№2** | ЦЕНТР + НОВЫЙ + НЧК (+ БОГДАНКА) |
| **№3** | НЮР + КУГЕСИ (+ БОГДАНКА) |

**Богданка** автоматически назначается водителю с меньшим числом людей.

**Порядок карточек** зависит от выбранного водителя:
- выбран №1 → сначала №1, затем №2, №3  
- выбран №2 → сначала №2, затем №1, №3  
- выбран №3 → сначала №3, затем №1, №2  

### Временные слоты

| Дни | Слоты |
|-----|--------|
| Пн–Чт, Вс | до **22:00**, до **23:00** |
| Пт–Сб | до **22:00**, **23:00**, **00:00**, **01:00** |

Если человек вышел раньше — его можно перенести в другой слот прямо из списка.

1. **Справка** — как пользоваться (тап — пропустить)  
2. **Выбор водителя** — дата, слоты, кнопки №1 / №2 / №3

4. **Обработка** — анимация распознавания адресов  
5. **Список развоза** — основной рабочий экран  
6. **Поездка завершена** — короткое сообщение перед возвратом в справку

## 🧠 Как устроена логика

Логика перенесена из Telegram-бота (`processor.py` + `address_data.py`):

- **Районы** — база адресов + синонимы («универ», «трактор», «50лет», «б.х.» и т.д.)
- **Fuzzy-matching** — опечатки и короткие формы все равно попадают в нужный район
- **Группировка по времени** — слоты зависят от дня недели
- **Роли** — офф, кух, кар, дост, клин, хост и др.
- **Несколько человек** — запись вида «2 чел.» разворачивается в отдельные строки
- **Неопределенные адреса** — отдельный блок внизу, можно вручную перенести в район

## 🚀 Запуск

### Для водителей
1. Установите APK на Android 8.0+  
2. Откройте **Развоз Квели**  
3. Выберите свой номер водителя  
4. Вставьте список из чата → **Обработать**  

### Для разработчиков
1. Откройте проект в **Android Studio** (Hedgehog / Iguana или новее)  
2. Дождитесь синхронизации Gradle  
3. Запустите на эмуляторе или устройстве (API 26+)  

```bash
# или из командной строки
./gradlew assembleDebug
```

## 📖 Как пользоваться (кратко)

1. Выбери водителя (№1 / №2 / №3)  
2. Вставь неотсортированный список  
3. Получи список по районам и времени  
4. Отмечай галочками тех, кого уже развез  
5. Если адрес не туда попал — ⇄ и перенеси  
6. Зажми человека, чтобы поменять порядок в районе  
7. Когда всех развез — **Завершить поездку**  

---

## 📝 Замечания

- Неопределенные адреса собираются в блок **«НЕОПРЕДЕЛЕНО»** — их можно вручную назначить в район или водителю  
- Сброс всей поездки происходит **только** по кнопке «Завершить поездку»  
- При обычном закрытии приложения прогресс сохраняется
