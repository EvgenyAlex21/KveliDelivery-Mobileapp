## 📌 О проекте

**Развоз Квели** — Android-приложение для водителей ресторана «Квели», которые развозят сотрудников по домам после рабочей смены.

Приложение автоматизирует обработку исходного списка сотрудников: вместо ручной сортировки сообщений водитель вставляет текст из рабочего чата, а приложение распознаёт людей, адреса, должности и время окончания смены. После обработки формируется структурированный список по временным слотам, районам и водителям.

Интерфейс построен на **Kotlin и Jetpack Compose**. Приложение позволяет управлять поездкой прямо во время развоза, корректировать распознанные данные и продолжать работу после повторного запуска.

## 🗺️ Распределение водителей и районов

| Водитель | Основные районы |
|:---:|---|
| **№1** | СЗР, ЮЗР |
| **№2** | ЦЕНТР, НОВЫЙ, НЧК |
| **№3** | НЮР, КУГЕСИ |

**БОГДАНКА** учитывается отдельно и распределяется между водителями №2 и №3 с учётом количества сотрудников.

Порядок карточек водителей в итоговом списке зависит от выбранного водителя: его карточка отображается первой.

## 🕒 Временные слоты

Приложение поддерживает два набора временных слотов и автоматический режим.

| Режим | Слоты |
|---|---|
| **Автоматический (AUTO)**, Пн–Чт и Вс | 22:00, 23:00 |
| **Автоматический (AUTO)**, Пт–Сб | 22:00, 23:00, 00:00, 01:00 |
| **До 23:00 (UNTIL_23)** | 22:00, 23:00 |
| **До 01:00 (UNTIL_01)** | 22:00, 23:00, 00:00, 01:00 |

Если в исходном списке уже есть сотрудники с ночным временем, соответствующие слоты сохраняются при формировании результата.

<ol>
  <li><b>Справка.</b> Краткое знакомство с приложением.</li>
  <li><b>Выбор водителя.</b> Выберите номер водителя и режим временных слотов.</li>

  <li><b>Обработка.</b> Приложение разбирает записи и определяет сотрудников, адреса, роли и время.</li>
  <li><b>Результат.</b> Список отображается по временным слотам, водителям и районам.</li>
  <li><b>Управление поездкой.</b> Отмечайте доставленных сотрудников, меняйте назначения и исправляйте данные.</li>
  <li><b>Завершение.</b> После окончания развоза нажмите кнопку завершения поездки.</li>
</ol>

### 🧠 Обработка списка

За разбор текста отвечает `ListProcessor`. В частности, он выполняет:

- нормализацию исходного текста;
- распознавание временных отметок и разделение записей по слотам;
- распознавание должностей и их сокращений;
- разбор записей с несколькими сотрудниками;
- определение района по адресу с использованием базы адресов и вариантов написания;
- формирование групп по времени, водителям и районам;
- выделение записей, для которых район определить не удалось.

Неопределённые адреса не теряются: они выводятся отдельно, после чего сотрудника можно вручную назначить в нужный район или водителю.

## 🚀 Запуск проекта

### Требования

- Android Studio (версия с поддержкой используемой версии Android Gradle Plugin);
- Android SDK с API 26 или выше;
- JDK, совместимый с конфигурацией Gradle проекта;
- Android-эмулятор или физическое устройство на Android 8.0+.

### Открытие в Android Studio

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/EvgenyAlex21/KveliDelivery-Mobileapp.git
   ```

2. Откройте папку проекта в Android Studio.
3. Дождитесь завершения синхронизации Gradle.
4. Выберите конфигурацию `app`.
5. Запустите приложение на эмуляторе или подключённом Android-устройстве.

### Сборка APK из командной строки

Windows PowerShell:

```powershell
.\gradlew.bat assembleDebug
```

Linux / macOS:

```bash
./gradlew assembleDebug
```

После успешной сборки APK обычно находится здесь:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 📚 Работа с базой сотрудников

Во время обработки списка приложение сохраняет сведения о новых сотрудниках в локальную базу. Для записи используются имя, должность, адрес и район.

База помогает повторно распознавать знакомые адреса и уточнять район по ранее сохранённым данным.

На экране выбора водителя доступны операции:

- **Просмотр** — открыть список сохранённых записей;
- **Экспорт** — сформировать файл Excel `.xlsx`;
- **Импорт** — выбрать Excel-файл на устройстве и загрузить записи в базу.

При импорте приложение обрабатывает записи из таблицы и сообщает результат, включая количество добавленных и пропущенных строк.

## 🔔 Обновления приложения

В проекте предусмотрен `UpdateChecker`: приложение может проверить доступность новой версии, получить информацию об обновлении, загрузить APK и предложить его установку через системный установщик Android.

Для установки обновления Android может запросить разрешение на установку приложений из данного источника — это системное ограничение платформы.

## 📝 Примечания

- Минимальная поддерживаемая версия — **Android 8.0 (API 26)**.
- Текущая поездка сохраняется при обычном закрытии приложения и восстанавливается при следующем запуске.
- Полный сброс поездки выполняется через действие завершения развоза.
- Если район не распознан автоматически, его можно назначить вручную.
- Содержимое локальной базы сотрудников хранится на устройстве.
